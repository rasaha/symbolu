  • PersonaProfile      - Defines persona characteristics

3.2 PERSONA ENGINE (engine.py)
-------------------------------
  Main class that coordinates all operations:
  
  • apply()            - Main entry point
  • _order_layers()    - Determines layer ordering
  • _compose_text()    - Generates styled text
  • _get_layer_header() - Creates section headers
  • _format_layer_content() - Formats layer content

  KEY CONSTRAINT: NEVER modifies layer contents

3.3 PERSONA SELECTOR (selector.py)
-----------------------------------
  Deterministic selection logic with 8 priority levels:
  
  1. User override (highest priority)
  2. Regulated domain check
  3. Domain-specific mapping
  4. Domain category patterns
  5. Tier-based selection
  6. Intent-based selection
  7. Bhava-based adjustment
  8. Fallback to neutral (lowest priority)

3.4 PERSONA REGISTRY (registry.py)
-----------------------------------
  Storage and retrieval system:
  
  • get()              - Retrieve persona by ID
  • get_safe()         - Retrieve with fallback
  • register()         - Add custom persona
  • list_all()         - List all personas
  • exists()           - Check persona existence

4. USAGE EXAMPLES

4.1 BASIC USAGE
---------------
from symbolu.mechanical.persona import PersonaEngine
from symbolu.mechanical.persona.models import RendererOutputV3, DHAResult

engine = PersonaEngine()

renderer_output = RendererOutputV3(
    symbolic_layer={"pattern": "seeking certainty"},
    practical_layer={"steps": ["assess risk", "define position"]},
    mirror_truth_layer={"reflection": "avoiding emotion"},
    metadata={"tier": "HYBRID", "domain": "trading", "intent": "how"}
)

dha_result = DHAResult(tone="resonance", confidence=0.82, justification={})

explain_log = {"meta": {"domain": "trading", "tier": "HYBRID", "intent": "how"}}

response = engine.apply(renderer_output, dha_result, explain_log)

print(f"Persona: {response.persona_id}")  # Output: analyst
print(f"Text: {response.text}")

4.2 USER OVERRIDE
-----------------
response = engine.apply(
    renderer_output, 
    dha_result, 
    explain_log,
    user_persona_override="coach"  # Explicit request
)
