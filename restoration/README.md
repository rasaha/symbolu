# Restoration Archive

This folder contains archived code, documentation, and experiments that are no longer actively used but preserved for reference.

## Structure

```
restoration/
├── experiments/
│   ├── sandboxes/       # Phase 11-14 experimental sandboxes
│   ├── version_history/ # Old versioned phase engines
│   └── acoustic_mappers/ # Acoustic unit mapper iterations
├── docs/
│   ├── phase_reports/   # Historical merge safety reports, audits
│   ├── test_data/       # Old test results and regression data
│   ├── validation/      # Historical validation documents
│   └── governance/      # Old remediation plans
└── scripts/             # Standalone scripts no longer in use
```

## Why Archived

These files were archived during housekeeping on 2024-12-19 to:
1. Reduce codebase clutter
2. Improve navigability
3. Preserve historical context without polluting active code

## Restoration

If you need to restore any file, simply move it back to its original location.
The git history preserves the original paths.
