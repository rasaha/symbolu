## What Phase-11 Is

Phase-11 is a **creative wind tunnel for expression**.

It is an isolated experimental space designed to explore whether:

- **Ontological routing** (layer selection, path traversal)
- **PPV influence** (Phonemic Propensity Vectors as soft bias signals)
- **Probabilistic choice** (random sampling, soft weights)

...can produce generative behavior that is expressive enough to matter—without committing to transformers, neural networks, or full probabilistic learning.

This is not intelligence. This is not meaning. This is structural experimentation.

## What Phase-11 Is NOT

Phase-11 is **not**:

- A production system
- A safety-certified module
- A governed pipeline component
- An intelligence or consciousness claim
- A replacement for Phases 1b–10
- A transformer or neural network
- A semantic understanding engine

Phase-11 makes **no claims** about:

- Correctness
- Auditability
- Safety
- Truth
- Meaning preservation

## Why Phase-11 Is Isolated

Phases 1b–10 are **deterministic, governed, and audit-oriented**:

| Property | Phases 1b–10 | Phase-11 Sandbox |
|----------|--------------|------------------|
| Determinism | Required | Explicitly disabled |
| Governance | Fail-closed | OPEN mode only |
| Verification | Mandatory | Not enforced |
| Ledger recording | Enforced | Optional/experimental |
| Safety claims | Made | Explicitly disclaimed |
| Template binding | Fixed | Soft/variable |

Phase-11 exists in a separate `/docs/experiments/` directory to:

1. **Prevent accidental integration** into the production pipeline
2. **Signal clearly** that nothing here is trusted
3. **Allow freedom** to explore without correctness pressure
4. **Maintain isolation** from governed audit trails

## What Questions Phase-11 Is Trying to Answer

### Primary Questions

1. **Can ontological layer selection influence generative output?**
   - If we softly bias toward certain layers (e.g., FORMING vs THINKING), does the output character change?

2. **Can PPV vectors serve as generative seeds?**
   - If we use the 8-dimensional PPV as a bias vector rather than a hash checksum, can it shape phoneme sequences or word selection?

3. **What happens when we allow non-determinism?**
   - Random sampling over ontological paths
   - Weighted selection instead of fixed routing
   - Probabilistic slot filling

4. **Where is the boundary between structure and noise?**
   - At what point does probabilistic freedom collapse into meaningless output?
   - Can we find a "zone" of useful generation?

### Secondary Questions

5. **Can path continuation produce coherent sequences?**
   - If we follow ontological edges probabilistically, do we get something resembling structure?

6. **What role does PPV weighting strength play?**
   - Light touch vs heavy bias—where is the useful range?

7. **Can this inform future Phase-12 verification?**
   - What would it mean to verify generative output?
   - What invariants could possibly hold?
