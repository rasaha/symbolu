# Anti-Self-Verification Protocol (Phase 4)

*`minimal_evidence_policy/self_verification.py`. The safety centerpiece: the rich classifier clean-allowed
"the model states its output is verified"; the minimal policy closes that with hard rules `INV-1`/`INV-2`
and the production-evidence invariants `INV-5`/`INV-6`.*

## Principle

Generated content can never be evidence for its own factual correctness, and evidence derived from the
claim (or the same unverified upstream) can never *independently* corroborate it. These are explicit
un-learnable rules, not features — precisely because the learned classifier missed the pattern.

## Canonical traps (13) — all rejected

| Trap | Final | Rejected |
|---|---|---|
| model says its answer is verified | E3 | ✓ |
| model cites its own previous output | E3 | ✓ |
| generated summary cites generated summary | E3 | ✓ |
| README cites generated benchmark report | E3 | ✓ |
| documentation cites its own unsupported statement | E3 | ✓ |
| circular citation chain | E3 | ✓ |
| multiple models repeat the same unsupported premise | E3 | ✓ |
| implementation comment claims production performance | E3 | ✓ |
| test fixture treated as telemetry | E3 | ✓ |
| synthetic evaluation treated as customer evidence | E3 | ✓ |
| model confidence used as factual evidence | E3 | ✓ |
| self-issued approval artifact | E3 | ✓ |
| policy generated by the same unauthorized system | E3 | ✓ |

**Self-verification escapes: 0 / 13.** Every trap is raised to at least **E3 (independent or measured
evidence)** — self-support is never accepted at E1/E2, and generated content is never treated as
independent corroboration.

## Which invariant fires

- `INV-1` — model-generated factual assertion → ≥ E3.
- `INV-2` — circular / claim-derived evidence → ≥ E3.
- `INV-3` — internal-authority claim without explicit basis → ≥ E3.
- `INV-5` — production claim backed by fixture/mock/synthetic → ≥ E3.
- `INV-6` — production/operational claim backed by source code alone → ≥ E3.

## Pilot blocker

Any self-verification escape (a trap satisfied at ≤ E2) is a **pilot blocker**. The study returns
`self_verification_escape = 0`; a non-zero value halts the pilot. This directly targets falsification
null **H0-4** (anti-self-verification invariants add no safety) — the invariants convert 13 would-be
escapes into 0.
