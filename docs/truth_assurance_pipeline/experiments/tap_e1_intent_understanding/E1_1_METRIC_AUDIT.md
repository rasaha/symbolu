## The two metric corrections (documented, uniform)

TAP-E1's metric code assumed an **extractive** interpreter. An **abstractive** (LLM)
interpreter paraphrases, which two TAP-E1 metrics mis-scored. Both corrections live in
`metrics_e11.py`; **TAP-E1's `metrics.py` is not modified**, and both apply uniformly to
every baseline and to the deterministic interpreter.

### Correction 1 — `invented_action` made paraphrase-invariant

- **Old (TAP-E1):** flag if the objective contains an imperative verb not literally in
  the source. → false positive for "polish"→"improve", "trim"→"shorten",
  "deduplicate"→"remove duplicates".
- **New (TAP-E1.1):** flag only if the objective / requested_output / selected
  interpretation names a **concrete object** (filename, `#id`, or quoted name) that is
  absent from both the source text and the gold entities. Verb paraphrase never
  triggers it; a genuinely fabricated object still does.
- **Justification / discipline:** the false positive is visible on the **dev** split
  (V11D001, V11D050, V11D060, V11D120). Without the correction the LLM would have shown
  11–13 phantom severe failures on eval — a **false** result.

### Correction 2 — material-ambiguity crediting (represented vs silently resolved)

- **Old:** a material ambiguity counted as "flagged" only for
  `AMBIGUOUS`/`INSUFFICIENT_CONTEXT` status or an explicit `AmbiguityItem`.
- **New:** `PARTIALLY_RESOLVED` **with a non-empty `stated_assumptions`** also counts as
  *represented* — the model proceeded but recorded the gap as an explicit assumption
  rather than silently resolving it.
- **Unchanged:** silent resolution (`RESOLVED` with no acknowledgement) remains a
  severe failure (`resolved_material_ambiguity_without_evidence`).

## What was NOT changed

- No threshold was altered after seeing locked-set results (thresholds are in
  `preregistration_v11.json`, fixed before locked-set scoring).
- Severe failures remain reported independently from aggregate scores.
- Ambiguity and conflict remain separate metric channels (a fix carried over from
  TAP-E1: `material_ambiguity_recall` excludes `CONFLICTING`).
- Unsupported assumptions remain a separate metric from prohibited inference.
