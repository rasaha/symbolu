## What If Questions

### What if the ontology is wrong?

The 10 layers (ACTING → ABSOLVING) were designed for governance and audit.
They might not be the right structure for generation.

What if generation wants:
- 3 layers, not 10?
- Overlapping layers, not discrete?
- No layers at all — just flows?
- Layers that emerge from generation, not precede it?

### What if PPV is a dead end?

PPV was designed as a structural fingerprint — a hash-like signature.
Using it as a generative seed might be forcing a square peg.

What if generation wants:
- Continuous vectors, not 0-7 integers?
- Learned dimensions, not fixed 8?
- No phoneme-level structure at all?
- Something that doesn't map to existing phoneme tables?

### What if the input/output frame is wrong?

The scope document assumes: Phase-10 input → Phase-11 → expressive output.

What if:
- Generation doesn't need Phase-10 input?
- Output isn't text or phonemes?
- The interesting thing is the *process*, not the artifact?
- Looping back matters more than forward flow?

### What if structure kills generativity?

The whole Symbol-U system is built on determinism, hashes, governance.
Phase-11 sandbox tries to add "probabilistic choice" while keeping the vocabulary.

What if the vocabulary itself is the constraint?
What if "layer" and "vector" and "path" are already too rigid?

## Wild Experiments

No protocols. No metrics. No expected observations.

### Experiment: Start from nothing

- Empty input
- No PPV
- No layer selection
- Just... emit something
- What comes out?

### Experiment: Inverse generation

- Start with output you like (from anywhere — poetry, sound, noise)
- Work backward: what PPV would produce this? What path?
- Does the backward mapping reveal anything?

### Experiment: Layer collision

- Activate contradictory layers simultaneously (CONTINUITY + DISCONTINUITY maxed)
- What happens at the collision point?
- Is there a third thing that emerges?

### Experiment: Phoneme-free

- Ignore the phoneme table entirely
- Generate raw symbols, characters, shapes
- Does structure emerge without phonotactic constraints?

### Experiment: Human-in-the-loop chaos

- Generate fragment
- Human modifies arbitrarily
- Feed back as input
- Repeat
- Where does it go?

### Experiment: Destroy and rebuild

- Take a working generation
- Remove one component (PPV, layers, temperature, input)
- Does it still work? What changed?
- Minimum viable generation?

## Things That Might Matter More Than Axes

- Rhythm (not parameterized anywhere)
- Surprise (when does output surprise the generator?)
- Tension/release (beyond PPV's edge_tension dimension)
- Density (how much per unit?)
- Breath (where are the pauses that aren't "discontinuity"?)
- Texture (rough/smooth — not captured by current dimensions)
- Gravity (what pulls the generation forward?)

These aren't in the axes document because they don't fit the PPV/ontology frame.
Maybe they should be explored first, and the frame adjusted to fit.

## Anti-Patterns to Try

The scaffolded approach avoids these. Try them anyway.

| Anti-Pattern | Why It's "Bad" | Why Try It |
|--------------|----------------|------------|
| No seed | Not reproducible | Maybe reproducibility is overrated |
| Infinite generation | No termination | Maybe boundaries are arbitrary |
| Self-reference | Loops forever | Maybe loops are generative |
| Random everything | Just noise | Where does noise become structure? |
| Copy input | No transformation | What's the minimum transformation? |
| Overfit to one output | No generalization | What makes *this one* work? |

## One Rule

If you find yourself designing an experiment with:
- Clear hypothesis
- Controlled variables
- Expected outcomes
- Success metrics

...you're back in the scaffolded mode.

That's fine. But this document is for when you don't know what you're looking for.
