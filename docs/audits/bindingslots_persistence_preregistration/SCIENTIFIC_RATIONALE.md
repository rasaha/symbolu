# Scientific rationale

The functional-routing Stage-1 screen (`ROUTING_PURITY_NOT_RESOLVED`) established:

- O1/O2 build correct-slot routing **during** the scaffold (correct-slot prob 0.50–0.97 near step 600).
- After withdrawal it **decays** (→0.14–0.28 by step 1200) while needle stays high.
- Needle collapses under slots-off but **frequently survives randomized addressing** → a diffuse,
  address-independent slot-read shortcut.
- H3 gradual withdrawal did not preserve clean address dependence.

This localizes the crux to **persistence of causal address dependence across scaffold withdrawal**,
not the within-window objective. The persistence phase therefore tests three retention mechanisms —
a standing residual address term (O1R), routing-parameter consolidation (H1), and a functional
teacher (H2) — each in isolation, against R0 and the O1 reproduction anchor, under the unchanged
frozen causal gate. The experiment must not optimize merely for raw needle formation: the Stage-1
result showed raw 5/5 formation coexisting with address-independent retrieval.

Hypothesis to test (not assumed): a mechanism that maintains address-dependence through withdrawal
will retain both the routing metrics **and** causal collapse at step 1200.
