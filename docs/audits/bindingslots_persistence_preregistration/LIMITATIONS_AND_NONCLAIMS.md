# Limitations and non-claims

This preregistration does **not** establish: that O1R works; that H1 works; that H2 works; that the
shortcut is conclusively localized; that BindingSlots is stable; that BindingSlots improves general
language modeling; natural-language transfer; production readiness; scale / sequence-length /
slot-count transfer; KDA readiness; KDA superiority; memory or speed benefit; architectural validation.

**The only claim produced by this task:** a persistence-isolation experiment has been preregistered
with frozen arms, seeds, gates, instrumentation, and evidence rules before training.

KDA validation remains **BLOCKED**. `READY_FOR_KDA_VALIDATION` is never emitted.
