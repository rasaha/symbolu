# Model Selection — Evidence & Scoring Assessment

Section 13. Classify every scoring input by provenance, and document the scoring/ranking semantics. Rule:
a model-generated estimate is **not** objective evidence; a hard constraint must never be overridden by a
higher aggregate score.

## 1. Scoring-input provenance classification

| Input | Real-deployment class | In current corpora | Source |
|---|---|---|---|
| Approved providers, privacy tier, residency/on-prem, tools/modality/context ceilings, cost/latency caps | **STATIC_POLICY / CUSTOMER_CONFIGURATION** | same | enterprise policy + task hard_constraints (`hard_filter`; `gate.py` #7–#17) |
| Fusion base-weights, per-source confidences, `telemetry_confidence_k`, `advisory_confidence`, constraint precedence, forbidden fields | **STATIC_POLICY** | same | `policy_v1.json` `evidence_fusion` |
| Utility weights (`w_quality/w_cost/w_latency`), per-task quality threshold | **CUSTOMER_CONFIGURATION** | same | corpus task `utility_weights`, `acceptable_quality_threshold` |
| Provider-declared overall quality tier | **PROVIDER_DECLARATION** (optimistically biased) | same | `model["declared"]["declared_overall"]` |
| Benchmark-measured capability scores | **HISTORICAL_BENCHMARK** | **SYNTHETIC_EVIDENCE** (simulator/stub-generated) | `model["measured"]["capability_scores"]` |
| Runtime telemetry quality estimate + `n` | **MEASURED_RUNTIME_SIGNAL** | **SYNTHETIC_EVIDENCE** (`simulator.telemetry_feed` / pilot stub outcomes) | `telemetry[mid][tclass]` |
| Model self-assessment suitability (arm G) | **MODEL_GENERATED_ESTIMATE** (biased +0.06) | **SYNTHETIC_EVIDENCE** (`advisory_feed`/`synth_advisory`) | `advisory["suitability_estimate"]` |
| Cost estimate = declared price × tokens | **PROVIDER_DECLARATION** | same (declared) | `estimate_cost` |
| Latency estimate = declared base × f(tokens) | **PROVIDER_DECLARATION**; pilot `base_latency_ms` is an author "observed-estimate" → **UNVERIFIED_ASSUMPTION** | same | `estimate_latency_ms`; pilot `registry.py` |
| Declared context window used for eligibility | **PROVIDER_DECLARATION functioning as UNVERIFIED_ASSUMPTION** (the "context trap": declared may overstate effective) | same | `hard_filter` context check |
| Ground truth (`true_quality/cost/latency`, oracle) | **SYNTHETIC_EVIDENCE** (oracle only; never seen by policy) | same | `simulator.py`; hidden task `_oracle` |

**Headline:** in every current corpus, the three "measured" quality signals (benchmark, telemetry,
advisory) are **synthetic** — deterministically generated by `simulator.py` / the credential-blocked
pilot Stub from ground truth plus fixed bias/noise constants. Only policy config, customer config,
declared provider facts, and one latency assumption are non-synthetic. **No real-provider evidence
exists** (the live pilot is credential-blocked). A model self-assessment is treated as low-weight,
bounded, cold-start-only input — never as objective evidence.

## 2. Scoring / ranking semantics

| Property | Value |
|---|---|
| Formula (default) | `utility = w_q·Q̂ − w_cost·(cost/cost_ref) − w_lat·(latency/lat_ref)`; `argmax`; tie-break by model id |
| Units | utility is dimensionless; cost normalized by max over eligible set; latency normalized by max over eligible set; `Q̂ ∈ [0,1]` |
| Normalization | cost/latency divided by the **max over the current eligible set** (relative, request-local) |
| Weighting | per-task `utility_weights` (CUSTOMER_CONFIGURATION); fusion weights = STATIC_POLICY × per-source confidence |
| Missing-data behavior | eligibility: missing/stale critical signal → UNKNOWN → INDETERMINATE or fail-closed (never silent pass). scoring: `fuse_quality` always returns a point estimate, falling back to declared/benchmark; **no confidence interval** |
| Tie-breaking | deterministic by model id (and, in variant C, lexicographic cost↑/latency↑/quality-margin↓/id↑) |
| Determinism | **fully deterministic** given inputs — all "noise" is SHA-256-hash-based, no RNG, no system clock (`now` is passed in). Reconciliation `reproducible()` verified byte-identical across two runs |
| Confidence | per-source confidence weights only; **no calibrated confidence/variance/LCB** on the fused `Q̂` |
| Versioning | `policy_version`/`registry_version` stamped on every decision; unknown gate version → all INDETERMINATE (fail-safe); reason codes append-only |
| Explainability | full per-decision record: eligible/eliminated (+reason+constraint+provenance), scored (+utility components + evidence list), fallback chain, abstain reason |
| Reproducibility | high — deterministic + version-stamped + frozen replay (`execution_gate/frozen/replay_v1`, aggregate `8b05b2da798a6222`) |
| Failure behavior | empty eligible pool → `abstained` / `NO_ELIGIBLE_MODEL` (fail-fast, safe); unknown reason code → candidate excluded (fail-closed) |

## 3. Calibration (from `MODEL_SELECTION_POLICY_OBJECTIVE_RECONCILIATION.md`)

- `Q̂` is **optimistically biased**: mean |Q̂ − true| = **0.035 (mature) → 0.058 (cold)**;
  optimistic-miscalibration (Q̂ ≥ Q_min but true < Q_min — the dangerous kind) = **0.041 → 0.090**.
- Calibration **degrades with stale evidence** (cold regime floor-violation 0.216 vs 0.081 mature).
- There is **no calibrated variance/LCB estimator**; a hard point-estimate floor therefore cannot
  guarantee true sufficiency.

## 4. Constraint-supremacy check (hard vs soft)

| Requirement | Enforced as | Status |
|---|---|---|
| Approved provider, privacy, residency, modality, tools, structured, context, hard cost/latency ceiling, reliability floor | **hard constraint** (eligibility gate) | ✅ correct — "no preference score can promote a model that fails any hard constraint" (`ENGINE_SPEC.md`); constraint supremacy holds |
| Minimum quality (`acceptable_quality_threshold`) | **soft target** in default policy (measurement only) | ⚠️ **documented divergence** — read by `metrics.py`, never by `policy.py`; a higher aggregate utility CAN select a below-floor model. Opt-in Policy B enforces a *predicted* floor but not a *guaranteed* one |

**Assessment:** aggregate score never overrides a *hard* constraint (constraint supremacy holds for the
gate). The one exception is **quality**, which the intended policy treats as a floor but the default
implementation treats as a soft term — a known, documented gap (reconciliation study), to be resolved as
an explicit opt-in mode during implementation, not silently.

## 5. Reproducibility verdict

Evidence and scoring semantics are **fully reproducible** (deterministic, version-stamped, frozen replay,
verified byte-identical). The *quality* of the evidence is the live issue — it is **synthetic and
optimistically biased**, not that it is irreproducible. This distinction matters for the migration
verdict: the Section-19 STOP condition "evidence and scoring semantics are not reproducible" does **not**
apply; the reproducibility is sound, only the real-world evidence is missing (credential-blocked).
