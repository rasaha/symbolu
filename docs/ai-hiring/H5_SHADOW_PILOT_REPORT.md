# H5 — Bounded Shadow-Pilot Report

## Harness & guarantees
`ai_hiring/validation/pilot.py` replays a synthetic cohort through the full lifecycle in a
single in-memory `ValidationEnv`. **All external effects go through deterministic
in-memory adapters** (`DeterministicHiringExecutionAdapter`, and deterministic ActionGate/TAP provider implementations used only for validation
providers). The pilot prohibits — and structurally cannot perform — production HRIS
writes, real candidate emails, calendar invites, payroll changes, identity provisioning,
employment-contract issuance, or any external irreversible action (`test_h5_boundary.py`
asserts no vendor SDK / transport imports anywhere in the validation tooling).

## Cohort (12 cases)
| Case | Requisition/action | Variation exercised |
|---|---|---|
| p01/p02 | Engineer / ADVANCE_STAGE | normal advance (group A/B) |
| p03 | HOLD / PLACE_ON_HOLD | hold outcome |
| p04 | REJECT / CLOSE_WITHOUT_SELECTION | reject/close |
| p05 | ADVANCE / PREPARE_OFFER | offer prepared, not issued |
| p06 | REJECT / PREPARE_REJECTION | rejection prepared, not sent |
| p07 | constrained authorization | obligations enforced |
| p08 | denied authorization | ActionGate denial |
| p09 | unsupported claim | review-required (no decision) |
| p10 | incomplete evidence | insufficiency (no recommendation) |
| p11 | override (REJECT vs ADVANCE proposal) | human override |
| p12 | execution mismatch | reconciliation MISMATCH → compensation |

Variation spans requisition type, seniority (title), evidence volume/completeness, rubric
requirements, recommendation confidence (assertion coverage), human-review outcome,
ActionGate outcome, execution outcome, and reconciliation outcome.

## Observed distribution (deterministic)
advancement_rate 0.60 · authorization_denial_rate 0.10 · execution_failure_rate 0.00 ·
reconciliation_mismatch_rate 0.10 · evidence_insufficiency_rate 0.083 (see
`ai_hiring/validation/metrics.py::cohort_metrics`).

## Data origin, exclusions, limitations
- **Origin:** fully **synthetic**, generated by the harness; no real or de-identified
  candidate data. Content hashes are synthetic tokens.
- **Exclusions:** production connectors, real communications, real identities.
- **Why sufficient for H5 (not production):** small enough to inspect manually, broad
  enough to exercise every critical branch (normal/review/authority/authorization/
  execution/reconciliation/remediation). It validates **behavioral correctness and
  governance boundaries**, not statistical performance, latency at scale, or real-world
  data distributions — no production-performance claim is made.
