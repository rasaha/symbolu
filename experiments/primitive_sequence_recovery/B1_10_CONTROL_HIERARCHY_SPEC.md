## 0. The three tiers

- **Tier 1 — generic valence control.** Broad unpleasant / pleasant mood **only**. Encodes **no** comparison,
  control, self-grounding, release, possession, or any other source-condition structure.
- **Tier 2 — generic source-condition control.** Broad other-conditioned/binding vs self-grounded/liberating axis,
  **word-agnostic and varṇa-agnostic**; must not reproduce any target word's specific facet combination.
- **Tier 3 — word-specific packet.** The actual `fidelity_bundle_v1` v3 binding/liberating packet for each word,
  **paraphrased into plain English** (Sanskrit stripped) per the §3 rule.

All three tiers are rendered in the **same plain-English register, length, and syntax** (§4), so the register/style
confound (C1 of `424b88b`) is removed.

## 1. Deliverable 1 — the exact fixed Tier-1 packet pair

A fixed 5-facet **negative** pool and 5-facet **positive** pool. Each word's Tier-1 packet takes the **first N**
facets (N = that word's v3 facet count) — deterministic, fixed, length-matched. Pure hedonic tone only.

**Tier-1 NEGATIVE (generic unpleasant):**
1. a heavy, aching mood that weighs the whole body down
2. a raw, unpleasant feeling that sits sourly in the chest
3. a dull, grey flatness that drains the colour from things
4. a sharp, uncomfortable soreness that keeps prickling
5. a bleak, sinking tone that darkens whatever it touches

**Tier-1 POSITIVE (generic pleasant):**
1. a light, glad mood that lifts the whole body up
2. a warm, pleasant feeling that spreads gently through the chest
3. a bright, clear tone that adds colour to things
4. a soft, agreeable smoothness that feels easy and nice
5. a fresh, cheerful lift that brightens whatever it touches

**Content audit:** every facet is a bodily/mood hedonic quality (heavy/aching/sour vs light/glad/warm). **None**
mentions others, results, comparison, holding/letting-go, approval, agency, or self-sufficiency. (Deliberately
avoids "settled/steady/restless/grasping," which would leak Tier-2 or Tier-3 structure.)

## 2. Deliverable 2 — the exact fixed Tier-2 packet pair

A fixed 5-facet **other-conditioned** pool and 5-facet **self-grounded** pool. Same "first-N" truncation. Encodes
the generic contingent-on-outside vs rests-in-itself axis, with **no** word-specific affect.

**Tier-2 OTHER-CONDITIONED (generic binding):**
1. a state that depends on how other people respond
2. a state that needs an outside result before it feels complete
3. a state that keeps measuring itself against someone else
4. a state that grips what it has and dreads losing it
5. a state propped up by approval coming from outside

**Tier-2 SELF-GROUNDED (generic liberating):**
1. a state that rests in itself without needing others
2. a state that feels complete without any outside result
3. a state that does not measure itself against anyone
4. a state that holds things loosely and can let them go
5. a state that stands on its own without needing approval

**Content audit:** every facet is a generic *dependence-vs-self-sufficiency* description. **None** names a specific
affect (contempt, torpor, cruelty, indulgence, defeat, etc.) or any Sanskrit/varṇa/pole/system term.

## 3. Deliverable 3 — plain-English rendering rule for Tier 3

The Tier-3 packet is the v3 facet set, **paraphrased** so it matches the other tiers' register. Rule:

1. **One clause per v3 facet**, following the shared template "a/an <quality> <inner-state> that <what it does>"
   (§4), ~9–13 words.
2. **Preserve the facet's affective content**; **remove** (a) all Sanskrit / technical terms (ghṛṇā, jāḍya,
   prāṇaśakti, dharma, mokṣa, anurakti, moha, kruratā, vitarka, avajñā, …), (b) proper nouns (Parama Puruṣa,
   Tantra), (c) pole / varṇa / system labels, (d) ornate punctuation and parenthetical glosses.
3. **No target-word leakage** (the word itself must not appear in its own packet), no pole labels, no varṇa labels,
   no system name.
4. Paraphrases are **authored blind to Tier-1/Tier-2 wording**, then an **independent reviewer audits** that (i) no
   Sanskrit/proper-noun remains, (ii) register/length match, (iii) the affect is faithful to the original v3 facet.
   The original v3 facet text is retained on the **hidden** side for provenance (not judge-visible).

**Worked example — pride (`pa,ra,da`, 3 facets):**

| pole | v3 facet (hidden provenance) | Tier-3 plain-English render (judge-visible) |
|---|---|---|
| binding | ghṛṇā — hatred/revulsion; downward pull toward the crude | a contemptuous feeling that looks down on others and recoils |
| binding | sarvanāśa — defeatist annihilation-thought; total defeat | a collapsing sense that everything is lost and undone |
| binding | peevishness / reactive irritability discharged at others | a prickly reactivity that takes offence and snaps back |
| liberating | the upward turn — goodwill that dissolves revulsion | a warm goodwill that turns upward and wishes others well |
| liberating | prāṇaśakti — vital life-force / winning resolve | a strong, steady energy that moves with sure resolve |
| liberating | forbearance that absorbs provocation; unreactive temper | an even, unbothered steadiness that does not flare up |

(The full six-word paraphrase set would be authored + audited + pre-registered the same way before any build.)

## 4. Deliverable 4 — length / style matching table

All facets across all three tiers obey one template so no tier is distinguishable by register.

| property | rule (all tiers) |
|---|---|
| syntactic frame | "a/an <adjective(s)> <inner-state noun> that <verb clause>" — one clause |
| length | 9–13 words per facet (target 11 ± 2) |
| facets per packet (word W) | **N(W)** = v3 facet count: pride 3, freedom 3, patience 4, courage 3, control 5, doubt 3 |
| register | plain modern English; no technical vocabulary |
| Sanskrit / foreign terms | **none** in judge-visible text (any tier) |
| proper nouns | none |
| ornamentation | none in any single tier only — punctuation/diction uniform across tiers |
| target-word / pole / varṇa / system tokens | none (enforced by the existing blinding filter + a per-facet audit) |
| truncation | Tier-1 & Tier-2 take the first N(W) pool facets; Tier-3 uses all N(W) paraphrased facets |

A pre-build **register-parity check** computes, per word, mean facet word-count and facet count for each tier and
requires them equal within ±2 words and identical facet count — so a judge cannot infer the tier from length/style.

## 5. Deliverable 5 — overlap audit (Tier 2 does not copy Tier 3)

Tier 2 is a fixed 10-facet generic set (dependence vs self-sufficiency). Tier 3 is per-word specific **affect**
content. The audit requirement: **no target word's Tier-3 facet combination is reproduced by Tier 2.**

| word | Tier-3 binding affect concepts | Tier-2 other-conditioned concepts | verbatim facet reuse? | shared *surface* facet |
|---|---|---|---|---|
| pride | contempt, defeat, prickly reactivity | depends-on-others, needs-result, compares, grips/dreads-loss, needs-approval | none | 0 |
| freedom | defeat, reactivity, indulgence-to-collapse | (same fixed Tier-2 set) | none | 0 |
| patience | contempt, torpor, fixation, grasping | " | none | 0 |
| courage | grasping, defeat, restless striving | " | none | 0 |
| control | grasping, fixation, over-talk, defeat, cruelty | " | none | 0 |
| doubt | reactivity, neglect-of-worth, torpor | " | none | 0 |

- **Verbatim reuse = 0** for all six words: Tier-2's facets are dependence/self-sufficiency statements; Tier-3's are
  specific affects (contempt, torpor, cruelty, indulgence, over-talk…). No facet string is shared.
- **Intended conceptual proximity (disclosed, not a bug):** Tier-2 "grips what it has and dreads losing it" is the
  *generic* cousin of Tier-3 grasping/fixation facets; that proximity is the **whole point** — Tier 2 must be a
  strong generic version of the source-condition axis so that `increment_over_source_condition` is a *demanding*
  test. Closeness on the axis is required; **facet-combination copying is forbidden** and is 0 here.
- **Distinctness metric to enforce at build:** for each word, Jaccard overlap of *content lemmas* between its Tier-3
  packet and the Tier-2 packet must stay below a pre-registered cap (e.g. ≤ 0.2), and no Tier-3 facet may be a
  paraphrase-equivalent of a Tier-2 facet (independent reviewer sign-off).

## 6. Deliverable 6 — revised cell count and aggregation formulas

**Packets per word:** 3 tiers × 2 poles = **6**. **Cells per word:** 6 packets × 2 contexts = **12**.
**Total cells:** 12 × 6 words = **72**. (Original B1.10 pilot's 12 cells for happy/peace/love remain separate and
untouched.)

Naming: `Pb_T` / `Pl_T` = binding/liberating packet of tier `T ∈ {spec, val, sc}`; `Cb` / `Cl` = binding /
liberating context. Judge blind to tier and pole; deterministic seeded shuffle over all 72 cells; compliance
one-liner for audit only.

Per word W and tier T:
```
margin_T(W) = [fit(Pb_T|Cb) − fit(Pl_T|Cb)] + [fit(Pl_T|Cl) − fit(Pb_T|Cl)]
```
Then:
```
specific_margin(W)                 = margin_spec(W)
valence_margin(W)                  = margin_val(W)
generic_source_condition_margin(W) = margin_sc(W)

# Comparison A
increment_over_valence(W)           = specific_margin(W) − valence_margin(W)
# Comparison B
increment_over_source_condition(W)  = specific_margin(W) − generic_source_condition_margin(W)
```
Aggregate = mean over the six words of each quantity. Also report each margin's two directional halves and all 12
cell means per word. **No verdict label emitted.**

### Interpretation (pre-specified)
- **`specific_margin > 0` alone = only pole legibility** (could be valence or generic framing).
- **`increment_over_valence > 0`** = the specific packet beats pure positive/negative matching.
- **`increment_over_source_condition > 0`** = **evidence of word-specific packet value beyond a generic self/other
  description** (the demanding result).
- **A > 0 but B ≈ 0** = the result is explained by **generic source-condition framing** (not word/varṇa-specific).
- **A ≈ 0 and B ≈ 0** = **no incremental packet-specific value** (valence/framing explain everything).
- **Either A or B negative** = the specific packet is **worse** than that control (off-axis facets hurting fit).
- Descriptive read only (6 words × judges); direction + consistency, not a powered inferential claim.

## 7. Deliverable 7 — failure modes and missing-data rules

**Failure modes**
- **FM1 — Paraphrase fidelity / experimenter degrees of freedom (new top risk).** Plain-English paraphrasing of
  Tier 3 gives the author latitude to make the packet fit the context better or worse. Mitigation: paraphrase
  **blind to the contexts and to Tier-1/Tier-2**, preserve affect faithfully, retain the original v3 facet on the
  hidden side, and require independent reviewer sign-off that each render is affect-faithful and register-matched.
- **FM2 — Tier-2 too weak or too strong.** If Tier-2 under-encodes the self/other axis, `increment_over_source_
  condition` is inflated; if it copies Tier-3 affect, it is deflated. Mitigated by the §5 distinctness cap +
  reviewer sign-off; Tier-2 wording is **fixed** (not per-word tuned).
- **FM3 — Residual register cues.** Even plain English can leak tier via subtle diction. Mitigation: the §4
  register-parity check (word-count/facet-count equality) before freeze; a blind pilot where a human tries to guess
  the tier from wording should be at chance.
- **FM4 — Varṇa-set overlap across the six words (non-independence).** ra/da/ka/ta recur, so the six Tier-3 packets
  are correlated; report per-varṇa contribution and treat as partially correlated, not six independent replications.
- **FM5 — Correlated / same-family judges.** Add **cross-family** judges (non-Anthropic) for the definitive run;
  ≥2 replicates per cell.
- **FM6 — Expected-pole mislabeling / reversible words (e.g. freedom-as-license).** Fix and pre-register each item's
  expected pole with rationale before any run.
- **FM7 — Attribution ceiling.** Even A>0 **and** B>0 shows only that word-specific packet content adds
  source-condition legibility beyond both controls, **to judges** — never ontology, semantic truth, Sanskrit
  privilege, generation utility, or individual-varṇa mapping (the packet stays a bag of constituent-varṇa readings).

**Missing-data rules**
- A judge cell that returns unparseable, refused, or out-of-range → **drop and re-draw** up to `k` times (fixed at
  build). No editing of judge output; no imputation.
- If a cell still has no valid rating after `k`, its cell-mean uses the remaining valid replicates.
- If **any** of a word's 12 cells has **zero** valid ratings, that word's affected margin(s) are marked
  `incomplete` and the word is **excluded from the aggregate** (reported explicitly; no imputation, no silent drop).
- If **> 15%** of all 72 cells are missing after re-draws, the run is declared **inconclusive** (not null, not
  positive) and reported as such.
- Position/order effects: deterministic seeded shuffle + (recommended) a second seed as a counterbalance replicate.

## 8. Deliverable 8 — recommendation: ready to build or not

**Conditionally READY to build.** The three-tier hierarchy resolves the two deepest confounds (register/style via
uniform plain-English rendering; generic-framing via Tier 2), and the statistics + interpretation are fully
pre-specified. Build only after this **pre-build checklist** is satisfied (all docs-only until then):

1. **Author the six Tier-3 plain-English paraphrases blind** to contexts and to Tier-1/Tier-2; independent reviewer
   signs off on affect-fidelity, no-Sanskrit, register-parity, and no target-word leakage.
2. **Freeze the six two-context sentences blind to the packets** and pre-register each item's **expected pole**.
3. **Run the §4 register-parity check** and a human tier-guessing pilot at chance.
4. **Enforce the §5 Tier-2/Tier-3 distinctness cap** (Jaccard ≤ 0.2; no paraphrase-equivalent facets).
5. **Add cross-family judges** + ≥2 replicates/cell; fix `k` and the missing-data thresholds.
6. Build as **new, separately-labeled files** (`b1_10_control_hierarchy_ext_*`), leaving the four original B1.10
   artifacts byte-unchanged; a separate evidence-freeze declaration; a mock-tested runner reusing B1.10 blinding +
   the §6 aggregation; **no verdict label**.

Until items 1–5 are done and pre-registered, the run would inherit FM1/FM2/FM3 and the result would not be
interpretable. With them done, the extension is a sound, demanding test of the standing question.
