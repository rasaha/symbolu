# Vocalic Resonance Tags — ṛ, ṝ, ḷ, ḹ (development-only)

Symbolic resonance layer for the four vocalic r/l sounds that were previously unmapped. **Not** the frozen
affliction backbone, **not** Sarkar's attested consonant mappings, **not** exact science — an interpretive
resonance layer whose value is judged downstream. Frozen artifacts untouched. `RESONANCE_LAYER /
DEVELOPMENT_ONLY`.

## Mappings

| Vowel | Core mapping | Binding (shadow) | Pole | Source |
|---|---|---|---|---|
| **ṛ** (ऋ) | **freedom** | rootlessness / escapism | freedom (liberating-side) | resonance — *ṛta, ṛṣi, ṛddhi*; rises toward ṝ=oṃ |
| **ṝ** (ॠ) | totality / **oṃ** | dissolution / self-loss | supreme / liberating | Sarkar — ṝ = oṃ (praṇava) |
| **ḷ** (ऌ) | arrangement / formation | rigid contrivance / over-fitting | neutral / constructive | corpus — √kḷp ("arrange, fit, form") |
| **ḹ** (ॡ) | explosion / breakthrough | destructive outburst / rashness | dynamic / liberating | Sarkar — ḹ = phaṭ |

## Key note (per operator)

**ṛ (ऋ) is not Ra (र).** The consonant **Ra = annihilation** (*sarvanāśa*, the defeatist annihilation-thought).
The vowel **ṛ carries no such affliction** — its resonance is **freedom**. Ra's affliction must not be inherited
onto ṛ.

## Provenance, honestly tagged

- **ṛ = freedom** — a resonance reading from ṛ's word-distribution (*ṛta* order/truth, *ṛṣi* seer, *ṛddhi*
  attainment) and the r-vocalic ascent toward oṃ; **not** Sarkar's acoustic root (he gives ṛ = niṣāda, a neutral
  musical note).
- **ṝ = oṃ/totality** and **ḹ = phaṭ/explosion** — Sarkar-attested cores; their binding shadows are derived
  symbolic readings.
- **ḷ = arrangement** — from the single root √kḷp that carries ḷ; differs from Sarkar's ḷ = *hummm* (disclosed).
- The **binding shadows** are symbolic distortions of each core (the way *au*'s surrender shadows into
  abandonment), not attested afflictions.

## Scope

`ṝ` is inflection/rare, `ḷ` occurs only in √kḷp, and `ḹ` occurs in **no** attested word — so these tags are mostly
inert on real input and are recorded for completeness of the vowel layer, not for corpus coverage. Kept in
`varna_vocalic_resonance_tags.json`, separate from the frozen backbone.
