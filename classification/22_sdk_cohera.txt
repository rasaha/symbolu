================================================================================
FEATURE: Cohera SDK (Hardware Abstraction SDK)
================================================================================
SDK for the Cohera hardware abstraction layer - Python bindings and
example kernels for ontology projection, phase attention, and video
processing on custom TCU (Tensor Compute Unit) hardware.
================================================================================

--- C Header ---
sdk/cohera/include/cohera.h                   # C API header

--- Python Bindings ---
sdk/cohera/python/cohera/__init__.py
sdk/cohera/python/cohera/attention.py          # Attention operations
sdk/cohera/python/cohera/device.py             # Device management
sdk/cohera/python/cohera/memory.py             # Memory management
sdk/cohera/python/cohera/metrics.py            # Performance metrics
sdk/cohera/python/cohera/ontology.py           # Ontology projections
sdk/cohera/python/cohera/stream.py             # Streaming
sdk/cohera/python/cohera/tcu.py                # TCU operations
sdk/cohera/python/cohera/tensor.py             # Tensor operations

--- Example Kernels ---
