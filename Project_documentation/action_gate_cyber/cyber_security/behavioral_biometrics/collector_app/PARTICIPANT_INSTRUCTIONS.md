# Participant Instructions

Thank you for helping test our data-collection tool. This takes about 5–10 minutes.

1. **Consent** — a summary appears first. It explains that we record only the *timing*
   of your typing and mouse use and the *category* of keys (letter, space, …), never
   the actual characters or any text. Read it. If you agree, tick the box and select
   **Confirm consent**. If not, close the page — nothing is collected.

2. **Setup** — enter the short participant code the researcher gives you, then pick the
   assigned task. Your device shows a pseudonymous device code (not your name).

3. **Calibration** — move the mouse and press a few keys for ~3 seconds so we can check
   the recording works. A green "Calibration OK" message starts the task.

4. **Recording indicator** — while a task runs you will see a red **● RECORDING** badge.
   Recording happens only on this page and only during the task.

5. **Task** — follow the on-screen prompts (type the neutral text, click the targets,
   etc.). Use neutral words only — do not type names, passwords, or anything private.

6. **Completion** — you will see a neutral message about the recording *quality* only.
   No identity or biometric result is shown.

7. **Your choices** — you may stop at any time. On the completion screen you can select
   **Delete this session's data** to remove your recording immediately.

You may repeat with another session if asked. Please use the same computer each time
where possible. Questions? Ask the researcher.
