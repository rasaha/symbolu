# ActionGate — Prioritized Product Roadmap

Every remaining item from the readiness audit and gap analysis, classified:
- **P0** — required before an enterprise **pilot** (safe, operable, integrable in one controlled account);
- **P1** — required before **commercial launch** (GA: scale, HA, compliance, SDKs);
- **P2** — future enhancement.

Each item cites the finding that motivates it. Nothing here invents a capability; items are gaps
already identified in `PRODUCT_READINESS_AUDIT.md` / `ENTERPRISE_GAP_ANALYSIS.md` / `TRL_ASSESSMENT.md`.

## P0 — before enterprise pilot

| # | item | why (finding) | dependency |
|---|---|---|---|
| P0-1 | **Promote & verify the isolated tier as the default deployment** (Ed25519 signing, durable SQLite replay/commit + signed audit ledger, mTLS trust-domain services) and make its test suite runnable in CI | the default runtime is still HMAC + in-memory + JSON snapshot; the hardened tier exists but is **unverified here** (`ecdsa` absent, tests skip) — audit §1/§2, TRL blockers | vendor/pin `ecdsa` (or move to a maintained crypto lib); fix cross-package test path |
| P0-2 | **Minimum observability**: structured logging, basic metrics export (Prometheus/OTel), health/readiness endpoints | codebase has **no logging/tracing/metrics export** (audit §4) — a pilot cannot run operationally blind | none |
| P0-3 | **One external network API** (thin REST over the gateway) so a pilot can integrate | **no REST/gRPC surface** today (gap analysis §1a) | P0-1 (stable service to expose) |
| P0-4 | **Key/cert provisioning + rotation runbook** (even if manual) and documented custody | keys are generated by `bootstrap.py` but there is **no rotation/revocation/lifecycle** (audit §1) | P0-1 |
| P0-5 | **Durable-store operations**: backup/restore + retention for the replay store and audit ledger | durable stores exist but **no backup/DR** (audit §1/§2) | P0-1 |
| P0-6 | **Pilot-scoped integration** (e.g., the pilot's CI trigger — GitHub Actions/webhook — or the specific target system) | only **Kubernetes** is a real enterprise integration (gap analysis §1c) | P0-3 |
| P0-7 | **Reproducible cross-package CI** running reference + gateway + MCP + isolated tiers | the isolated suite fails to collect standalone; the tier is unverified (audit §6, TRL) | P0-1 |

**P0 exit criterion:** a single-account pilot can be deployed with real asymmetric crypto, durable
replay/audit, a network API, minimum telemetry, and a documented key/backup procedure — all verified
in CI.

## P1 — before commercial launch

| # | item | why (finding) | dependency |
|---|---|---|---|
| P1-1 | **HSM/KMS integration** for all signing keys + **encryption at rest** for durable stores | pure-Python `ecdsa`, no HSM/KMS, no at-rest encryption (audit §1, compliance) | P0-1 |
| P1-2 | **HA + horizontal scale**: replace single-file SQLite with a replicated durable backend (e.g., Postgres), add leader election / shared claim-once, and publish **throughput/latency benchmarks** | single-node storage; **no HA/scale/perf evidence** (audit §2, TRL) | P0-1 |
| P1-3 | **Full observability**: distributed tracing (OTel), dashboards, alerting, SLOs | only in-process counters today (audit §4) | P0-2 |
| P1-4 | **External WORM audit export + automated retention** | audit is durable+signed but not external-immutable (compliance) | P0-5 |
| P1-5 | **Operator RBAC + SoD + admin authN** for policy change, audit read, broker operation | no operator access-control model (compliance) | P0-1 |
| P1-6 | **Compliance package**: SOC2/ISO27001/PCI/HIPAA control mappings, PII classification/masking, DPA handling, DR plan | no control mappings or PII handling (compliance) | P1-1..P1-5 |
| P1-7 | **Published network SDKs** (≥2 languages) + versioned API contract + OpenAPI/proto | Python-only in-process API + one client helper (audit §6) | P0-3 |
| P1-8 | **Policy registry + signed distribution + staged rollout** pipeline | policy is signed/versioned but has no deployment pipeline (audit §1) | P0-1 |
| P1-9 | **Priority enterprise integrations** by demand: AWS/GCP execution, ServiceNow/Jira approvals, GitHub Actions/Jenkins/Azure DevOps triggers | only K8s+MCP today; the engine already models approvals/`linked_ticket`/`correlation_id` so these are adapters (gap analysis §1) | P0-3, P0-6 |
| P1-10 | **Product & onboarding docs**: quickstart, tutorials, integration guides | strong internal specs, no product docs (audit §6) | P0-3 |

**P1 exit criterion:** multi-node HA deployment with HSM-backed keys, encryption at rest, external
WORM audit, RBAC, full observability, compliance mappings, SDKs, and a policy pipeline.

## P2 — future enhancement

| # | item | why (finding) |
|---|---|---|
| P2-1 | **gRPC + streaming** transport | REST covers pilot/GA; gRPC is an efficiency/ecosystem add (gap analysis) |
| P2-2 | **Multi-action atomicity / saga coordinator** across several authorized actions | architecture study "genuinely new": the engine is single-action; composition is a layer above |
| P2-3 | **Continuous / real-time control extension** (e.g., robotics) | architecture study: current model is discrete + synchronous |
| P2-4 | **Formal safety model / model-checking** of the commit protocol | research position: determinism is tested, replay/TOCTOU argued not proven |
| P2-5 | **Blockchain/notary-anchored external audit** beyond WORM | audit is tamper-evident; anchoring is a further integrity add (audit §1) |
| P2-6 | **Long-tail integrations** (SAP, niche ITSM/CI) | demand-driven adapters (gap analysis §1c) |
| P2-7 | **Advanced remediation / planner** | **only if** future evidence overturns R2 (measured STOP for an LLM planner); currently unjustified |
| P2-8 | **Multi-region active-active** | beyond single-region HA |

## Sequencing note [interpretation]
P0 is dominated by **promoting and verifying what already exists** (the isolated tier) plus
**operability + one network API** — i.e., productizing, not inventing. P1 is the classic
**scale/HA/compliance/SDK** GA work. P2 items (sagas, real-time, formal proof) are the ones that
would extend the *security model or scope*, and several are explicitly gated on new evidence.
