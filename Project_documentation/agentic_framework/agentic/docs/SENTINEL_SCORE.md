## The Key Insight

ChatGPT's recommendation proved correct:

```
Before MCP:  Proactivity = liability (agent does random things)
After MCP:   Proactivity + min_confidence 0.7 = feature (controlled automation)
```

The combination of:
- **MCP Gateway** for tool execution
- **Proactive Scheduler** with min_confidence 0.7
- **Default OFF** requiring explicit enablement

Transforms autonomous execution from a liability into a differentiated feature.
