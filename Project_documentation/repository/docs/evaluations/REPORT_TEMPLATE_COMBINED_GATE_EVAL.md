# Combined Gate Evaluation Report Template

This template is auto-generated by `scripts/eval_combined_gates.py` as
`combined_gate_report.md` in the output directory.

The report is structured around 5 decision questions:

1. **Are the gates alive?** — firing rates, per-category breakdown
2. **Does either gate help more than it harms?** — output quality comparison
3. **Do the two gates compose safely?** — overlap rate, output length delta
4. **Which gate is carrying value?** — Vritti-only vs Guna-only comparison
5. **Agentic integration justified?** — stability and interpretive value

After answering, choose one decision outcome (A/B/C/D) and one follow-up action.

See `Project_documentation/repository/docs/runbooks/RUNBOOK_COMBINED_GATE_EVAL.md` for full instructions.
