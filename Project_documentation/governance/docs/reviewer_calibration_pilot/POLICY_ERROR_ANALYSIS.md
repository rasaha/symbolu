# Policy Error Analysis (Phase 18)

*The framework for attributing reviewer↔system disagreements to their cause. **No policy is modified in
this phase**, and — because there are no real reviewers — **no errors are attributed**: error analysis
requires human disagreements, which do not exist here.*

## Error categories (ready to populate)

Every disagreement, once real reviews exist, is attributed to exactly one:

- **policy rule error** — a frozen rule produces a wrong obligation that reviewers consistently reject;
- **reviewer-guide error** — reviewers misapply the framework because the guide is unclear;
- **source-metadata error** — the derived source role/authority is wrong;
- **missing context** — the artifact lacked context the reviewer needed;
- **evidence-binding error** — available evidence was mis-associated;
- **EvidenceAssurance error** — the frozen EA delivery is disputed;
- **AssertionGate error** — the frozen assertion outcome is disputed;
- **ActionGate disagreement** — the native ActionGate outcome is disputed;
- **irreducible ambiguity** — a genuine domain judgment call;
- **reviewer mistake** — the reviewer erred (caught by adjudication);
- **ground-truth instability** — reviewers themselves disagree irreducibly.

## Proposed policy changes

**None.** Proposing a policy change requires supporting cases from real reviewers, a measured safety
effect, a measured utility effect, and an overfitting assessment — none of which exist without human
data. Per the governing constraint, the policy is **not modified in this phase** regardless, and no
change is justified on zero human evidence.

## What can be said now

- The framework distinguishes **policy defects** from **guide defects** from **irreducible ambiguity** —
  the distinction that determines whether a future disagreement leads to a rule change (Phase 20 option
  3), a guide revision (option 2), or neither.
- The self-verification / circularity categories are **critical**: any reviewer finding the system *too
  permissive* there would indicate a policy defect, not a guide issue — but this can only be established
  by real reviewers.
