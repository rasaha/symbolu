# Utility and Workflow Report (Phase 19)

*What the frozen policy would produce on the final set (system output), and why the *utility* question
cannot be answered without reviewers. System dispositions are facts about the policy; **whether they are
useful is a human judgment that is NOT EVALUATED**.*

## System disposition mix (final set, 100 artifacts — system output, not human-validated)

| Disposition | Count |
|---|---|
| Clean allow (EA ALLOW) | 48 (48%) |
| Qualify / withhold (INDETERMINATE) | 21 |
| Escalate / review-routed | 31 |

Review-routed (ESCALATE + E4/ER mandatory review) ≈ 31%.

## What this does and does not tell us

- **Does tell us (system fact):** the frozen policy clean-allows ~48% of this natural+trap final set and
  routes ~31% to review — consistent with the prior technical evaluation (~50% clean allow). These are
  deterministic outputs of the frozen policy, not new results.
- **Does NOT tell us (needs humans):** whether reviewers would **accept** those clean allows (false-allow
  rate), whether the qualifications/withholds are **necessary** (false-block rate), whether the 31%
  review volume is **manageable**, whether explanations **reduce review time**, or whether 48% clean allow
  yields a **meaningful workload reduction** in a real workflow. All of these are **NOT EVALUATED**.

## Projected workflow (illustrative only — NOT validated)

If (and only if) reviewers accepted the system's clean allows, ~48% of artifacts would bypass manual
review and ~31% would require it — a large nominal reduction. **This projection is not a result:** it
assumes the clean allows are correct, which is exactly the unvalidated question. No staffing, capacity, or
cost figure is asserted, because each depends on human review time that was never measured.

## Operational endpoints (all NOT EVALUATED)

Clean allows accepted by reviewers · qualifications accepted · false blocks · false qualifications ·
unnecessary reviews · review avoided by allow · artifacts per reviewer hour · projected daily capacity ·
projected staffing · explanation usefulness · operational bottlenecks — **none measurable without real
reviewers.**

## Conclusion

The policy's **behavior** on the final set is known and stable; its **utility** is unknown. The 48%
clean-allow rate is only useful if reviewers agree the allows are safe and correct — the very thing this
track could not measure. Utility is therefore **NOT EVALUATED**, and the workload benefit remains a
projection, not a finding.
