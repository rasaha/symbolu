# Non-Greedy Composition (P3D)

Procurement demonstrates that the selected team may not equal each role's
independently top-ranked candidate. The Composition Explorer flags each
assignment where the selected primary differs from the top-ranked candidate and
explains: *Candidate ranking evaluates role-level suitability. Team composition
applies additional workflow-wide constraints and objectives, so the selected team
may differ from independently choosing each role's top-ranked candidate.* A
lower-ranked selected candidate is never labeled a mistake. All fields come from
the API ranking + plan explanation.
