# Role Requirements View

For each AI-agent-eligible role: identity, functional requirements, enterprise
constraints, authority/permission boundaries and provenance. Compiler,
enterprise-policy and AWC-derived fields carry visible source badges; missing
values render honestly ("Not supplied" / "None"). No requirement is inferred.

## Permission display boundary

The "Authority & permission boundaries" section displays permission **requirements**
used as eligibility inputs (role-required and prohibited permissions, authority
ceiling, human-review requirement). These are inputs to the eligibility decision —
P3C does not show composition-time permission proposals, permission-feasibility
scoring or the granting/provisioning of permissions (those are P3D+).
