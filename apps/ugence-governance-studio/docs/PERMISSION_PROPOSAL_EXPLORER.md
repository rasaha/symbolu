# Permission Proposal Explorer (P3D)

Composition-time permission proposals per selected assignment: proposed
permissions (least-privilege), categorized permissions (REQUIRED / REQUESTED /
PROPOSED / PROHIBITED / HUMAN_REVIEW / GOVERNANCE_OWNED), authority scope,
feasibility state and infeasible reasons, and the proposal fingerprint. A
persistent notice states: *Permission proposals are planning artifacts. They do
not grant, provision or activate permissions.* P3C's permission **requirements**
remain on the role/registry screens; P3D adds the composition-time **proposals**.
Grant / provisioning / authorization language is forbidden by the terminology gate.
