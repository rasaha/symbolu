# Design System

Enterprise research-lab aesthetic: neutral dark surfaces, restrained typography,
high information density, visible provenance. Status tones (eligible, ineligible,
indeterminate, invalid, authority, review, governance, deterministic) each pair a
color with a glyph and an accessible label so no state is color-only. Primitives:
StatusPill, Badge, Card, Section, Field, Fingerprint, and explicit
loading/error/empty states.
