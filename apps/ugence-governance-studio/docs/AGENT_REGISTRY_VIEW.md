# Agent Registry View

Renders the pinned synthetic registry. Each agent shows profile fields and its
capability evidence grouped by DECLARED / MEASURED / OBSERVED. Every agent and
evidence item is labeled synthetic; expired evidence stays visible and flagged.
Profile and evidence fingerprints are shown.

## Permission display boundary

Each agent's **requested permissions** and maximum authority scope are displayed as
registry facts used during eligibility. P3C displays these permission requirements;
it does not produce or display composition-time permission proposals, and it never
grants or provisions permissions.
