# Varṇa Lexicon — AUTHORITATIVE set (user-confirmed)

> Source: `Sanskrit_letters_full.docx`. **positive** = liberating/balance pole (consonant) or positive
> acoustic essence (vowel); **negative** = the binding/distortion pole or negative meaning. Same fields
> for vowels and consonants. The rule uses these two and nothing else.

## How to write each letter (avoiding the two-"da" / two-"ta" trap)
The **retroflex Ṭa-varga** (ṭ ṭh ḍ ḍh ṇ, tongue curled back) and the **dental ta-varga** (t th d dh n,
tongue on teeth) are different sounds with different vṛttis. Three unambiguous ways to write the retroflex:
- **Diacritic (IAST):** `ṭ ṭh ḍ ḍh ṇ ṣ` — e.g. `ḍa`.
- **ITRANS capitals:** `T Th D Dh N` and `Sh` (=ṣa) — e.g. `Da` = Ḍa. **lowercase** `t th d dh n` and `sh`
  (=śa) stay **dental/palatal** — e.g. `da` = dental Da.
- **English words:** just type them — g2p picks the sound (voiced *th* in *the/this* → Ḍa; plain *d* → Da).

So `Da` = ड Ḍa (Shyness), but `da` = द Da (Peevishness). The reading always prints the Devanāgarī + varga so
you can see which one you got.

### Source fidelity (Ca, Ja, Ma, Ra, Va, Śa, Ṣa, Sa)
These eight entries were corrected to align with the Sanskrit acoustic-root source (see each entry's
`source_vritti` / `source_notes` in `lexicon_authoritative.json`). Read each row in three layers:

- **source-derived acoustic root / vṛtti** — the propensity the source attributes to the sound
  (e.g. Ca → *viveka*; Ja → *ahaṁkāra*; Ra → *agnitattva/prāṇaśakti + sarvanāśa*; Va → *dharma + jalatattva*;
  Śa → *rajoguṇa/artha*; Ṣa → *tamoguṇa/kāma*; Sa → *mokṣa/sattvaguṇa*).
- **negative / worldly distortion** (the `negative` column) — the binding/distorted form the lens treats as
  the worldly pole under the worldly-reference rule.
- **remedial / dissolved counter-pole** (the `positive` column) — for several letters this is a *derived*
  counter-pole (the dissolution of the worldly distortion), **not** a meaning stated verbatim in the source
  (e.g. Ca *Viveka*↔*Aviveka*, Ja humility↔ego, Va *Dharma*↔*Adharma*). Where the source itself names the
  positive root (Ra *agnitattva/vitality*; Sa *mokṣa/sattva*), it sits in the positive column directly.

Corrections of note: **Ra** — fire/*agnitattva* moved OFF the negative side onto vitality; only *sarvanāśa*
stays negative. **Va** — *Dharma* is the sustaining positive pole, worldly distortion is *Adharma* (prior
*Satya* removed). **Ja** — worldly pole is *ahaṁkāra* (ego), no longer *dambha* (which duplicated Ṅa).
**Ma** — *praṇāśa* added alongside *praśraya*. **Ca** — *viveka* root (prior Ekāgratā/Vikṣepa replaced).
